# CSV Import Studio v5 — Space Edition

โปรแกรม Python Desktop สำหรับ Windows: นำเข้าไฟล์ CSV/TXT จากเครื่องลง MySQL ผ่านหน้าจอกราฟิก **ธีมอวกาศ**

## เริ่มใช้งานอย่างง่าย (Windows)

1. ดาวน์โหลดไฟล์ ZIP แล้วคลิกขวา **Extract All...** (ต้องแตกไฟล์ก่อนใช้งาน)
2. เครื่องต้องติดตั้ง **Python 3.10 ขึ้นไป** พร้อม **tcl/tk and IDLE** จาก [python.org](https://www.python.org/downloads/windows/) ระหว่างติดตั้งเลือก Add Python to PATH ด้วย
3. **ทดลองโปรแกรมก่อน:** ดับเบิลคลิก `open_demo.pyw` เปิดหน้าต่างโดยไม่ใช้ CMD; หากไม่เปิด ให้ดับเบิลคลิก `run_demo_windows.bat` เพื่อดู Error ใน CMD ที่ยังค้างอยู่
4. **ใช้ MySQL จริง:** ดับเบิลคลิก `install_windows.bat` **เพียงครั้งแรก** เพื่อติดตั้ง PyMySQL (ต้องมีอินเทอร์เน็ต) จากนั้นเปิด `open_app.pyw` หรือ `run_windows.bat` (อันหลังแสดง Error ผ่าน CMD)
5. เลือก CSV → ตรวจ Preview และจำนวนแถว → พิมพ์ Schema/Table → ทดสอบเชื่อมต่อ MySQL → กำหนดคอลัมน์ → เลือกโหมด → กด **เริ่มนำเข้า**

> `open_demo.pyw` เป็นโหมดทดสอบ UI เท่านั้น **ไม่เขียนข้อมูลลงฐานข้อมูลจริง**. ไฟล์ `open_app.pyw` สำหรับการเชื่อมต่อจริง. ต้องติดตั้ง Python ก่อน ไม่มีไฟล์ `.exe` ในชุดนี้

## หน้าจอและการแก้ชื่อคอลัมน์

**Preview ใหญ่ขึ้น:** ตารางขยายตามพื้นที่ว่างของหน้าจอ มี scroll ทั้งแนวตั้ง/แนวนอน กด `A−`/`A+` เพื่อปรับความชัดในการอ่าน และกด **ขยายตัวอย่าง ↗** เพื่อเปิดตารางในหน้าต่างขนาดใหญ่ เห็นข้อมูล 20 แถวแรก (จำนวนแถวทั้งหมดนับแยกตามไฟล์จริง)

**แก้ชื่อคอลัมน์ง่ายขึ้น:**

1. กด **Column Mapping** หรือปุ่ม **✎ แก้ชื่อคอลัมน์** ใน Preview
2. คลิกชื่อในคอลัมน์ **ชื่อใน MySQL (คลิกแก้)** หนึ่งครั้ง แล้วพิมพ์ชื่อใหม่ได้ทันที
3. กด **Enter** หรือ **Tab** เพื่อบันทึก หรือคลิกบริเวณอื่นเพื่อบันทึก; กด **Esc** เพื่อยกเลิก
4. ดูชื่อที่แก้แล้วในตาราง Mapping และหัวตาราง Preview; ชื่อจาก CSV จริงอยู่ในคอลัมน์ซ้าย ไม่เปลี่ยนชื่อภายในไฟล์ต้นฉบับ (ดับเบิลคลิกหัวตาราง Preview เพื่อไปแก้คอลัมน์นั้นได้ด้วย)
5. **Data Type** คลิก Dropdown ในแต่ละแถว เลือกได้เมื่อสร้าง Table ใหม่

**ตัวอย่าง:** CSV ต้นทางมีคอลัมน์ `REF_ID`, พิมพ์เปลี่ยนชื่อปลายทางเป็น `customer_ref`. เมื่อเลือก Create ระบบจะสร้างคอลัมน์ `customer_ref` ใน Table MySQL และใส่ค่าจาก `REF_ID` เดิมลงไป โดยไม่แก้ไฟล์ CSV

หากใช้ Append, Upsert หรือ Replace กับ Table เดิม ชื่อปลายทางที่กรอกจะต้องเป็นชื่อคอลัมน์ **ที่มีอยู่แล้วใน MySQL** เพราะโปรแกรม **ไม่แก้โครงสร้าง Table เดิม**

## รูปแบบการนำเข้าเดิม (ไม่เปลี่ยน)

- **Create New:** สร้างตารางใหม่; หาก Schema ยังไม่มี ติ๊กสร้าง Schema ใหม่ก่อน
- **Append:** เพิ่มแถวลง Table เดิม
- **Upsert:** หาก Key เดิมมีอยู่ อัปเดตแถว; หากไม่พบ เพิ่มแถว (ต้องมี Unique/Primary Key ที่รองรับ)
- **Replace All:** ลบแถวเดิมแล้วใส่ข้อมูลใหม่ (มีการยืนยันโดยพิมพ์ `REPLACE` และรองรับเฉพาะ InnoDB)

**ข้อมูล CSV จะไม่ถูก Clean หรือเติม/ลบ `'`** โดยระบบ. สำหรับเลขบัตร/รหัสที่ต้องรักษาเลข 0 นำหน้า ให้เลือก TEXT/VARCHAR; Data Type ตัวเลข/วันที่ทำให้ MySQL แปลงข้อมูลตามประเภทที่เลือกได้

## ไฟล์สำคัญ

- `app.py` — หน้าตา Tkinter และการทำงาน GUI (ใหม่: Space Edition, ขยาย Preview, แก้ชื่อคอลัมน์คลิกเดียว)
- `importer_core.py` — การอ่าน CSV / การเชื่อมต่อ/เขียนลง MySQL **เหมือน v4 ทุกไบต์**
- `assets/space_header.png`, `assets/space_sidebar.png` — ภาพประกอบธีมอวกาศที่สร้างใหม่ ไม่ต้องมี Pillow ตอนเปิดโปรแกรม
- `tests/` — Core + UI regression tests
- `ui_space_preview.png` และ `ui_space_mapping.png` — ภาพหน้าจอจริงของโปรแกรมในโหมดทดลอง

## การทดสอบ

`python -m unittest discover -s tests -v` (การทดสอบ GUI ต้องใช้ Desktop/X11; Linux แนะนำ `xvfb-run -a python -m unittest discover -s tests -v`)

รันชุดทดสอบทั้งหมด **33 กรณีผ่าน** (Core 22 + UI 11) โดยจำลอง Database และใช้ GUI สาธิต ยังไม่ได้เชื่อมต่อ MySQL จริงของผู้ใช้ แนะนำให้ทดลองบน Schema ทดสอบก่อนส่งเข้าระบบสำคัญ

## ข้อจำกัดและความปลอดภัย

- ต้องมีสิทธิ์ MySQL ตามโหมด; โปรแกรมไม่ส่ง CSV ไปเซิร์ฟเวอร์ภายนอกโดยตัวเอง แต่จะส่งค่าที่อ่านไปยัง MySQL Host ที่กรอก
- ระวังข้อมูลส่วนบุคคล หลีกเลี่ยงการส่งภาพหน้าจอที่มีข้อมูลจริงทางช่องทางสาธารณะ
- สำหรับฐานข้อมูล Production โปรดใช้บัญชีสิทธิ์จำกัดและเส้นทางเชื่อมต่อที่ปลอดภัยตามนโยบายขององค์กร
- ไฟล์ `.pyw` จำเป็นต้องเชื่อมโยงกับ Pythonw บน Windows หากไม่แน่ใจให้เปิด `.bat` เพื่อดูข้อความผิดพลาด
