CSV Import Studio v6 — Multi-Database Space Edition
==================================================
1. ติดตั้ง Python 3.10+ (รวม Tkinter) จาก python.org
2. แตกไฟล์ ZIP
3. ดับเบิลคลิก install_windows.bat (ครั้งแรกเท่านั้น) เพื่อรองรับ MySQL/PostgreSQL/MongoDB
4. ทดลองหน้าจอ: open_demo.pyw
5. เชื่อมต่อฐานข้อมูลจริง: open_app.pyw
6. เลือก CSV → กำหนดชื่อปลายทาง → เลือก MySQL/PostgreSQL/SQLite/MongoDB → ทดสอบการเชื่อมต่อ → Import

เปิด .pyw แล้วไม่มีอะไรขึ้น? ใช้ run_demo_windows.bat / run_windows.bat เพื่อตรวจ Error
SQLite: ไม่ต้องติดตั้งฐานข้อมูล Server มีเพียง Python ก็เปิด/สร้างไฟล์ .db ได้
MongoDB: Database / Collection ไม่ใช่ SQL Schema / Table
PostgreSQL: ต้องมี Database อยู่แล้ว โปรแกรมสร้าง Schema ใหม่ได้

โปรดอ่าน README_TH.md ก่อน Replace ข้อมูลจริง
