CSV Import Studio v5 - Space Edition

1) แตกไฟล์ ZIP: คลิกขวา > Extract All...
2) หากติดตั้ง Python แล้ว: ดับเบิลคลิก open_demo.pyw
3) ถ้าไม่ขึ้นโปรแกรม: ดับเบิลคลิก run_demo_windows.bat เพื่อดูข้อความ Error
4) ต้องการ MySQL จริง: ดับเบิลคลิก install_windows.bat ครั้งแรก
5) แล้วดับเบิลคลิก open_app.pyw เพื่อเปิดโปรแกรมใช้งานจริง

วิธีแก้ชื่อคอลัมน์:
ไปแท็บ Column Mapping > คลิกช่อง 'ชื่อใน MySQL (คลิกแก้)' > พิมพ์ชื่อใหม่ > Enter
การแก้ชื่อมีผลเฉพาะคอลัมน์ปลายทางใน MySQL ไม่เปลี่ยน CSV ต้นฉบับ

Preview: กดปุ่ม A+/A- หรือ 'ขยายตัวอย่าง' เพื่อดูข้อมูลได้ชัดขึ้น
